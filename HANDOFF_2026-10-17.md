## What This Project Does

This workspace holds a decision record for shared agent memory. `swarm_memory/` is the package under construction. SQLite stores candidates, decision instances, fact bindings, dissent, the recall log, and recorded use. A fact binds only when a numeric confidence clears a risk bar that code computes. The losing value stays as dissent. Hy-Memory is intended to index only the current bound sentence. It is not installed.

`README.md` and `swarm_shared_memory.py` are an older scaffold. They write straight to Hy-Memory. They are not the decision path. Do not point `SwarmAgent` at `MemoryService` unless the user asks.

`context-mode/` is a separate git repository, ignored by the parent. It is the planned store for tool traces. This package refuses traces. `hmss/` is an untracked competitor tree that was assessed. Do not import it into `swarm_memory`.

**Tech Stack:** Python 3.14.8, sqlite3 in the standard library, pytest 9.1.1. No `pyproject.toml` and no `requirements.txt` for `swarm_memory`.
**Architecture Pattern:** Library plus a service object. One writer. The decision model, when it is called, sees one packed case. It does not see the whole store, and it does not output the numeric bar.

### What was already assessed and rejected

HMSS, in untracked `hmss/`, was compared with this package. Three ideas were taken and are in commit `d970892`:

1. Rank current bindings by recorded use.
2. Skip an oversized recall hit instead of cutting the fact text.
3. An exact repeat of the current fact or preference value does not create a new decision.

The usefulness score is `mean + bonus - cost`, with `c = 0.5`, prior `0.5`, prior weight `1.0`, and cost weight `0.05 * text_length / 100`. Total trials are the sum of stored trials. With `c = 0.5`, an unseen item outranks an item that was shown and ignored, and it can outrank a lightly cited item. Do not change the formula so that one citation always wins. Tests that lock the intended inequalities are `tests/test_utility.py:4` and `tests/test_utility.py:10`.

## Known Issues & Tech Debt

- [ ] `save_instance` and `bind` commit on separate connections. A crash between them can leave a bound instance with no binding row. `swarm_memory/service.py:87` then `swarm_memory/service.py:103`.
- [ ] `Decision.reason` is not a column. The status is stored. The reason is not.
- [ ] `fact_bindings.risk_floor` receives `decision.final_class`, which may be higher than the floor. `swarm_memory/service.py:103`.
- [ ] Confidence above 1 still binds. The comparison is only `< bar`. `swarm_memory/decide.py:77`.
- [ ] `except Exception` around the index write discards the exception text. `swarm_memory/service.py:105`.
- [ ] A preference write with `fact_key is None` never reaches the preference branch. It is stored as an experience. `swarm_memory/decide.py:44` runs first. The `fact_key is None` check inside the preference branch is unreachable.
- [ ] A preference whose value equals the current value of a non-preference key returns `duplicate` before `evaluate`. The binding stays. It is not recorded as `preference_key`. `swarm_memory/service.py:43`.
- [ ] `note_use` accepts any decision id. It does not check that the id is a current binding.
- [ ] Usefulness is not inferred. A runtime that never calls `note_use` leaves every binding unseen, and shorter text then ranks slightly higher because of the length penalty.
- [ ] No test names `identity.`, `auth.`, `delete`, or `patient_facing`.
- [ ] The evidence gate checks that experiences exist and come from different agents. It does not check that an experience is true. Two agents can still write the same false experience.
- [ ] The confidence range check (0 to 1) applies to facts only, not preferences. `swarm_memory/decide.py`.
- [ ] Parent `README.md` still tells a reader to install Hy-Memory and run `swarm_shared_memory.py`. That path is not the decision record.
